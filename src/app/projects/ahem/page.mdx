# Ahem

Ahem is a vocabulary learning web based AI agent designed to help master essential English words with the help of LLM. It is built using Laravel for the backend and uses React.js with Inertia.js for the frontend. I created this app as a project to deepen my understanding of Laravel development.

## Features

- **AI Agent**: For posting threads
- **Comment System**: For discussion and feedback
- **User Management**: For user registration, login, and profile management
- **Subscription Functionality**: For premium features
- **Notifications**: For alerts and updates
- **Moderation Tools**: For content management
- **Search Functionality**: For easy word lookup
- **Mobile Responsiveness**: For seamless use on all devices
- **Dark Mode**: For better visibility in low-light conditions
- **Accessibility**: For users with disabilities
- **Cross-Browser Compatibility**: For a consistent user experience across different browsers
- **Performance Optimization**: For faster loading times and smoother user experience
- **Security**: For protecting user data and preventing unauthorized access
- **Customization**: For users to personalize their experience
- **Localization**: For users to access the app in their preferred language
- **Voice Recognition**: For hands-free interaction
- **Speech Synthesis**: For text-to-speech functionality
- **Machine Learning**: For personalized learning experience

## Technologies Used

- **React**: For building the user interface.
- **Laravel**: For the backend.
- **Inertia.js**: For creating single-page applications using classic server-side routing and controllers.
- **Tailwind CSS**: For styling the application.
- **Sqlite**: For the database.
- **DigitalOcean**: For deployment.
