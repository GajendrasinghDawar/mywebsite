# Personal Website

This is my personal website. It is built with Next.js and [MDX](https://mdxjs.com/).

## What’s on the site

- `Home` - a short introduction, location, availability, and links to GitHub and LinkedIn
- `Projects` - selected projects plus an archived section
- `Library` - a curated list of articles, books, and essays I am learning from
- `Couplets` - a small collection of Urdu shayari and couplets

## Getting Started

### Prerequisites

- Node.js 24+ recommended
- npm

### Install

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open `http://localhost:3000`.

## Scripts

- `npm run dev` - start the development server
- `npm run build` - build the site for production
- `npm run start` - start the production server
- `npm run lint` - run linting
